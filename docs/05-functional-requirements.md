# Functional Requirements

## 1. Introduction

Functional requirements describe the main operations and services that the Spare Parts Management System must provide to its users.

## 2. Functional Requirements Table

| ID | Requirement | Description | Priority |
|---|---|---|---|
| FR-01 | Search by Product Name | The system shall allow customers to search for spare parts by product name. | High |
| FR-02 | Search by Product Code | The system shall allow customers to search for spare parts using a product code. | High |
| FR-03 | View Product Details | The system shall display the product name, price, technical specifications, and availability. | High |
| FR-04 | Add Product | The system shall allow authorized store managers to add new products. | High |
| FR-05 | Update Product | The system shall allow authorized store managers to update product information. | High |
| FR-06 | Deactivate Product | The system shall allow authorized store managers to deactivate products. | Medium |
| FR-07 | Add to Cart | The system shall allow customers to add products to their shopping cart. | High |
| FR-08 | Update Cart Quantity | The system shall allow customers to change product quantities in their cart. | High |
| FR-09 | Calculate Total Price | The system shall calculate the total price of the products in the shopping cart. | High |
| FR-10 | Check Product Availability | The system shall verify product availability before confirming an order. | High |
| FR-11 | Register Order | The system shall register an order after validating the required information and product availability. | High |
| FR-12 | Generate Order ID | The system shall generate a unique identifier for each successfully registered order. | High |
| FR-13 | View Order Status | The system shall display the current status of an order. | Medium |
| FR-14 | View Customer Orders | The system shall allow customers to view their own orders. | Medium |
| FR-15 | Update Order Status | The system shall allow authorized store managers to update order statuses. | Medium |

## 3. Conclusion

These functional requirements define the essential services of the Spare Parts Management System. They cover product search, product management, shopping cart operations, order registration, and order tracking.
